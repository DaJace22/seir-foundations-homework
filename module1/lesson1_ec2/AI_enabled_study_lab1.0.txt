Databases
	There are two main types of databases. Relational and Non-Relational. Relational databases store data in tables using rows and columns. There’s usually a key in one table that ‘relates’ to another table (Primary Key/Foreign Key). Non-Relational databases store different data types such as documents, key/value pairs, and graphs. It’s used more for storing and retrieving different, unrelated documents. Personally, I use MS SQL mostly in my career.

COBOL
	COBOL stands for COmmon Business Orientated Language. The coding language uses a column based format. For example, the first 6 digits are the line numbers. Column 7 dictates either a comment, or line continuation. Columns 8-11 identify divisions, sections, and paragraphs. Columns 12-72 are the actual code. 72 is the limit in order to fit on a punch card. COBOL is one of the oldest coding languages and is used by many banks. It’s in high demand because most of the coders are either retired or dead.

SWIFT
	SWIFT stands for Society for Worldwide Interbank Financial Telecommunication. It was established in 1973 to move money from one currency to another digitally. It handles the transactions from the appropriate accounts by sending messages for deductions or additions. It updates the users’ transaction details digitally, while the banks themselves handle the monetary changes internally. As of 2015, SWIFT linked more than 11,000 banks in over 200 countries and territories. ISO 20022 is the newer messaging standard SWIFT moved to for cross-border payments, replacing the older MT format. MT messages use short, tagged text fields with tight character limits, while ISO 20022 uses structured XML that can carry more detailed data, like structured addresses and detailed payment information. The two main swaps are MT103 to pacs.008 for customer payments and MT202 to pacs.009 for bank-to-bank transfers. SWIFT ran both starting in March 2023 until 22 November 2025. Since then, old MT payment instructions only get a limited contingency conversion, so receiving banks get ISO 20022 only.

APIs
	REST (the most common style behind modern APIs) stands for Representational State Transfer, and API stands for Application Programming Interface. It’s a software interface for passing information, usually in a request and response format. Some common HTTP style methods are Post, Get, Put, and Delete. These are equivalent to CRUD. A request would usually consist of a header (e.g. for authentication), endpoint, method used, and any parameters passed. APIs are how most AI models are used.

Next-lab prep: GET vs POST, JSON, and validation
	GET only retrieves data, so it’s safe to repeat. In our lab, GET /accounts/100001 looked up Alice’s account. POST sends data in the request body to create or change something, like POST /payments submitting a payment. JSON (JavaScript Object Notation) is the text format most APIs use to send that data, built from key-value pairs like {"question": "What does return code 8 mean?"} from our /ask call. APIs must validate incoming data because anything sent by a client could be wrong or malicious, so the rule is never trust input. In our lab, FastAPI rejects badly formed JSON with an HTTP 422 error before it reaches COBOL, and the COBOL core then applies business rules, like rejecting a zero-dollar payment with return code 8. Checking at more than one layer like this is called defense in depth.
